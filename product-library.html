当前版本 v2026.10.09
  • 修复新设备下载后产品图裂开：根因是 S3 同步的 latest.json 里 imageMap 格式不一致——上传端写入的是裸 hash 字符串 imgId→hash，而下载端按对象 remote[id].hash 读取，读到 undefined 导致请求 images/undefined.enc、图片全下载失败。新增兼容助手 imgHashOf() 统一取 hash（兼容旧字符串与新 {hash} 两种格式），上传跳检与下载三处一并修正，新旧云端数据均可正确下载图片。
  • 同步面板增加 HTTPS / Mixed Content 拦截守卫：「同步地址」标题加红字提示「Endpoint 必须 HTTPS」（HTTPS 页面下用 http:// 会被浏览器拦截 Mixed Content）；onSyncCfgChange 检测到 HTTPS 页面下 endpoint 以 http:// 开头时弹 toast 提醒，避免 GitHub Pages 等 HTTPS 部署下同步静默失败。
  • 同步配置导出 / 导入：同步区新增「⤓ 导出配置 / ⤒ 导入配置」按钮，将 S3 同步设置打包为 JSON（参考思源笔记 S3 同步）：含 Endpoint / Region / Bucket / Addressing / AccessKey（明文）及加密的 SecretKey / 口令 blob；另一设备导入后输入相同加密口令即可解锁，免重填大部分配置。
  • 修复同步时间显示为 UTC（慢 8 小时）：同步日志、状态徽章、上次同步时间统一改为北京时间（UTC+8），新增 fmtBeijing() 助手格式化所有同步时间。
  • 新增「系统版本」导航入口：将版本更新记录从产品库底部独立成面板，便于随时查看每次修改事项。
  • 已合并优化预览（分页/排序/时间戳/金额格式化）并补充外贸标准字段（HS 编码/认证/MOQ/交期/原产国/销售单位/可样品）。
  • 修复报价单内容区不渲染 + 草稿持久化。
  • 修复面板嵌套空白。
  • 产品图存储迁移至 IndexedDB。
  • PWA 封装 + S3 加密多端同步：新增「同步」面板（手动/自动触发、开关/频率/重试/数据类型/冲突策略配置；配置文件或环境变量注入；deploy.mjs 自动 bump 缓存版本号；file:// 仍可用全部本地功能）。
  • 非安全上下文防御加固：file:// 打开时手动同步入口拦截并提示双击 start-server.bat。
  • 修复 SigV4 签名 403：path-style 下 CanonicalURI 漏 bucket；修正 virtual 模式 Host 头、逐段 URI 编码；新增 s3ErrorDetail 显示 S3 错误码。
  • 七牛 400 排查加固：HEAD 无响应体时改用 GET+Range 取详情；inferRegionFromEndpoint 兜底；validateSyncCfg 必填校验。
  • 区域不匹配自动定位：Region↔Endpoint 一致性校验 + 「🔍 自动探测区域」按钮遍历七牛各区域回填。
